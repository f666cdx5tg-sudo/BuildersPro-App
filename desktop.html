How to sync 3 devices (iPhone, iPad, Desktop)
1. Get one free GitHub token at github.com/settings/tokens — check gist scope only
2. Enter that same token on all three devices
3. On ONE device (say iPhone): tap Push. Copy the Gist ID it shows you
4. On the other two devices: paste that Gist ID into "Link to another device's sync" above, tap Link, then tap Pull
5. After that, all three point at the same Gist — Push on whichever device you changed data on, Pull on the others to catch up
6. This is manual, not automatic — nothing syncs until you tap Push or Pull
