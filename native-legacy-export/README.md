# One-time export from the old native app (v5.40.1)

This is the old SwiftData BuildersPro app (exactly as it was at v5.40.0) plus one
button: **Export everything to the web app**. It only reads your data.

1. Double-click **Setup.command** in THIS folder. Xcode opens.
2. Plug in your iPhone, pick it at the top of Xcode, press **Play ▶**.
3. In the app, tap **Export everything to the web app** → Save to Files → iCloud Drive.
4. In the web app: Sync → **Restore from iCloud** → pick that file.

Same bundle id and iCloud container as the installed old app, so it opens on top of it with all your jobs.
